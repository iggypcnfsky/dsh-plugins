# Iggy Love DSH Plugins

A format-1 plugin market index for the Docs and Sheets plugins for DeepSeek Harness.

Add this URL in DeepSeek Harness under **Plugins → Discover → Add index source**:

```
https://iggypcnfsky.github.io/dsh-plugins/index.json
```

Plugins:

- [Docs](https://github.com/iggypcnfsky/dsh-docs) — `@iggylove/dsh-docs`
- [Sheets](https://github.com/iggypcnfsky/dsh-sheets) — `@iggylove/dsh-sheets`

Both packages declare `dsh.bundle`, expose a Web client, and require DSH `>=0.2.2-0 <0.3.0-0`.
